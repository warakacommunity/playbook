# `<Bucket>`

**Category:** Visual tag

Simple container for items in `Ranker` tag. Can be used to group items in `List` tag.

## Attributes

| Attribute | Type | Required | Default | Description |
|---|---|---|---|---|
| name | string | **yes** | — | Name of the column; used as a key in resulting data |
| title | string | **yes** | — | Title of the column |
| default | true,false | no | — | This Bucket will be used to display results from `List` by default; see `Ranker` tag for more details |
