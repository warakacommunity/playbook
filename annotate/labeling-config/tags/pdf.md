# `<Pdf>`

**Category:** Object tag

The `Pdf` tag is used to display a PDF document from a URL.

## Attributes

| Attribute | Type | Required | Default | Description |
|---|---|---|---|---|
| value | string | **yes** | — | Data field value containing the URL to the PDF |
