# `<MultiChannel>`

**Category:** Object tag

MultiChannel tag for grouped display of channels on the same plot

## Attributes

| Attribute | Type | Required | Default | Description |
|---|---|---|---|---|
| height | number | no | `200` | height of the plot |
| showAxis | true,false | no | `true` | whether to show both axes |
| showYAxis | true,false | no | `true` | whether to show the y-axis |
| fixedScale | true,false | no | — | whether to use a fixed scale for all channels. If not set, inherits from parent TimeSeries tag |
