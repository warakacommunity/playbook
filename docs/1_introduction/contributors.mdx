# Our contributors

The AfriPlaybook is written and maintained by volunteers: researchers, students, linguists, translators, annotators, and community organisers. Thank you to everyone who has helped build it.

## Contributors on GitHub

These are the people who have contributed to the [playbook repository](https://github.com/warakacommunity/playbook), listed alphabetically. The list updates each time the site is published.

<ContributorGrid />

## Not listed here?

Much of the work behind a guide like this never appears on GitHub: reviewing chapters, translating pages, annotating data, and organising people. If you have helped in one of these ways, open an [issue on GitHub](https://github.com/warakacommunity/playbook/issues/new) or tell us on [Discord](https://discord.gg/ChNPHV2PPS) so we can credit you.

If you have committed to the repository but are missing from the list, check that the email address you commit with is linked to your GitHub account.

To join them, see [How to contribute](./how-to-contribute.md).
