# Collaboration and Shared Tasks

Beyond standing communities, African NLP advances through organised collaboration: shared tasks, benchmarks, workshops and open challenges that pool effort towards a common goal. No single group can cover hundreds of languages, so these are how scattered work becomes shared infrastructure.

:::tip[Key points]

- A shared task gives everyone the same problem, data and scoring, and leaves the field a benchmark.
- Joining a shared task is an efficient way to add a new language: you inherit the protocol and the company.
- Workshops and IndabaX events are where people meet, plan and recruit.
- Open data challenges and dataset calls fund and reward new datasets.
- If you are starting out, join an existing effort before working alone.

:::

## Shared tasks and benchmarks

A shared task sets a common problem, a common dataset and a common way of scoring, then invites everyone to take part. Many teams build data and models for the same goal at once, and the field gets a benchmark to measure progress against afterwards.

African NLP has used this pattern often and well:

- **AfriSenti** produced Twitter sentiment datasets for 14 African languages and became a SemEval shared task ([Muhammad et al., 2023a](../references.md#muhammad-2023)).
- **MasakhaNER 2.0** coordinated named-entity annotation across 20 African languages ([Adelani et al., 2022a](../references.md#adelani-2022)).
- **IrokoBench** gives the community a shared yardstick for large language models on 17 African languages ([Adelani et al., 2024](../references.md#irokobench-2024)).

Contributing to a shared task is one of the most efficient ways to add a new language to the map. You inherit the protocol and the tooling, and you work alongside others doing the same thing.

## Workshops and open challenges

Workshops and challenges are where the community gathers, plans and recruits:

- **The AfricaNLP workshop**, held each year alongside a major conference, is a main venue for new African-language work.
- **The Deep Learning Indaba and its IndabaX events** build the skills and relationships that make collaboration possible ([Deep Learning Indaba](../references.md#deep-learning-indaba)).
- **Open data challenges** turn this energy towards data directly. Zindi competitions and the AI4D African Language Dataset Challenge rewarded the creation of open datasets that did not exist before ([Siminyu et al., 2021](../references.md#siminyu-2021)).
- **Dataset calls** continue the pattern. The Deep Learning Indaba 2026 call for African datasets invited text, audio, video and other data in areas such as language and culture, health and agriculture ([Deep Learning Indaba, 2026](../references.md#indaba-datasets-2026)).

If you are starting out, joining one of these is often a better first move than working alone, because the community will help you build something that lasts.
