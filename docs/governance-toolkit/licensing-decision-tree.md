# Licensing Decision Tree

Use this page to choose a dataset licence that matches what contributors consented to, what source licences allow, and what the community wants.

## Step 1: Start from consent and source terms

1. Read the consent form and list any limits (for example, non-commercial use, no public release, or only research use).
2. List all source datasets and their licences.
3. If any source licence conflicts with your intended release, stop and revise the plan before collecting more data.

## Step 2: Decide the release path

- **If consent and source terms allow unrestricted public release:** choose an open licence (for example CC BY or CC BY-SA).
- **If attribution is required but broad reuse is allowed:** keep CC BY-style terms and define required citation text.
- **If community benefit-sharing or control is required:** use a community-centred licence pattern (for example NOODL or Esethu) and document the obligations.
- **If consent or law restricts sharing:** use a controlled-access release with an access committee and written use conditions.

## Step 3: Validate before release

Before publication, confirm all four items are true:

- The chosen licence matches contributor and speaker consent.
- The project can legally grant every right in the licence text.
- Contributor agreement and annotator contract terms are compatible with the licence choice.
- The dataset card and ownership records describe the same licence and restrictions.

If any check fails, return to Step 2 and revise.
